GatherReminder 1.0.1
==================

Languages: English / Français / Deutsch


FRANÇAIS
--------

PRÉSENTATION

GatherReminder affiche une petite fenêtre de rappel pour les compétences de
détection liées aux métiers de récolte.

Vous pouvez enregistrer jusqu'à 3 compétences de détection par personnage.
LOTRO ne permet d'avoir qu'une seule détection active à la fois : lorsque le
rappel apparaît, cliquez simplement sur la détection que vous souhaitez
activer. La fenêtre se ferme automatiquement après ce choix.

FONCTIONNALITÉS

- Jusqu'à 3 compétences de détection enregistrées par personnage.
- Une seule détection active à la fois.
- Sauvegarde individuelle pour chaque personnage.
- Position de la fenêtre mémorisée.
- Indicateur "OK" après le choix de la détection.
- Fermeture automatique après avoir choisi une détection.
- Clic droit sur une case pour vider uniquement cette case.
- Bouton "Plus tard" pour fermer temporairement le rappel.
- Réaffichage après une résurrection solo.
- Pas de popup automatique après une mort en communauté ou en raid.
- Si le personnage est encore en combat après la résurrection, le rappel
  attend la fin du combat.
- Interface disponible en français, anglais et allemand.

COMMANDES

/gather          Afficher ou masquer la fenêtre.
/gr              Raccourci de /gather.
/grem            Raccourci de /gather.
/gather reset    Vider les 3 cases.
/gather center   Recentrer la fenêtre.
/gather help     Afficher l'aide.

INSTALLATION

1. Décompressez l'archive.
2. Copiez le dossier "Dusk" dans :
   Documents\The Lord of the Rings Online\Plugins\
3. En jeu, tapez /plugins refresh.
4. Chargez GatherReminder depuis le gestionnaire de plugins LOTRO.
5. Activez le chargement automatique si vous souhaitez avoir le rappel à
   chaque connexion.

UTILISATION

Au premier lancement, glissez jusqu'à 3 compétences de détection dans les
cases. Lorsque le rappel apparaît, choisissez simplement celle que vous voulez
activer. Une seule détection peut être active à la fois.

Les cases inutilisées peuvent rester vides.

REMARQUE

L'API Lua de LOTRO ne permet pas de vérifier directement si une compétence
de détection est réellement active. GatherReminder utilise donc votre clic
dans la fenêtre comme confirmation du choix.


ENGLISH
-------

OVERVIEW

GatherReminder displays a small reminder window for gathering tracking skills.

You can save up to 3 tracking skills per character. LOTRO allows only one
tracking skill to be active at a time: when the reminder appears, simply click
the tracking skill you want to activate. The window closes automatically after
that choice.

FEATURES

- Up to 3 saved tracking skills per character.
- Only one tracking skill can be active at a time.
- Per-character saved settings.
- Saved window position.
- "OK" indicator after choosing a tracking skill.
- Automatic close after choosing a tracking skill.
- Right-click a slot to clear only that slot.
- "Later" button to temporarily dismiss the reminder.
- Reminder after a solo resurrection.
- No automatic popup after a fellowship or raid defeat.
- If the character is still in combat after resurrection, the reminder waits
  until combat ends.
- Interface available in English, French and German.

COMMANDS

/gather          Show or hide the window.
/gr              Short alias for /gather.
/grem            Short alias for /gather.
/gather reset    Clear all 3 slots.
/gather center   Recenter the window.
/gather help     Display help.

INSTALLATION

1. Extract the archive.
2. Copy the "Dusk" folder into:
   Documents\The Lord of the Rings Online\Plugins\
3. In game, type /plugins refresh.
4. Load GatherReminder from LOTRO's Plugin Manager.
5. Enable automatic loading if you want the reminder every time you log in.

USAGE

On first launch, drag up to 3 tracking skills into the available slots. When
the reminder appears, simply choose the one you want to activate. Only one
tracking skill can be active at a time.

Unused slots can remain empty.

NOTE

The LOTRO Lua API does not provide a reliable way to directly verify whether
a tracking skill is currently active. GatherReminder therefore uses your click
in the reminder window as confirmation of the choice.


DEUTSCH
-------

ÜBERSICHT

GatherReminder zeigt ein kleines Erinnerungsfenster für die Suchfertigkeiten
der Sammelberufe.

Pro Charakter können bis zu 3 Suchfertigkeiten gespeichert werden. LOTRO
erlaubt nur eine aktive Suchfertigkeit gleichzeitig: Wenn die Erinnerung
erscheint, klicken Sie einfach auf die Suchfertigkeit, die Sie aktivieren
möchten. Danach schließt sich das Fenster automatisch.

FUNKTIONEN

- Bis zu 3 gespeicherte Suchfertigkeiten pro Charakter.
- Nur eine Suchfertigkeit kann gleichzeitig aktiv sein.
- Einstellungen werden pro Charakter gespeichert.
- Fensterposition wird gespeichert.
- "OK"-Anzeige nach der Auswahl einer Suchfertigkeit.
- Automatisches Schließen nach der Auswahl.
- Rechtsklick auf ein Feld, um nur dieses Feld zu leeren.
- "Später" schließt die Erinnerung vorübergehend.
- Erinnerung nach einer Solo-Wiederbelebung.
- Keine automatische Einblendung nach einer Niederlage in Gruppe oder
  Schlachtzug.
- Falls der Charakter nach der Wiederbelebung noch im Kampf ist, wartet die
  Erinnerung bis zum Kampfende.
- Oberfläche auf Deutsch, Englisch und Französisch.

BEFEHLE

/gather          Fenster anzeigen oder ausblenden.
/gr              Kurzer Alias für /gather.
/grem            Kurzer Alias für /gather.
/gather reset    Alle 3 Felder leeren.
/gather center   Fenster zentrieren.
/gather help     Hilfe anzeigen.

INSTALLATION

1. Archiv entpacken.
2. Den Ordner "Dusk" nach folgendem Pfad kopieren:
   Documents\The Lord of the Rings Online\Plugins\
3. Im Spiel /plugins refresh eingeben.
4. GatherReminder im LOTRO-Plugin-Manager laden.
5. Optional den automatischen Start aktivieren.

VERWENDUNG

Beim ersten Start bis zu 3 Suchfertigkeiten in die verfügbaren Felder ziehen.
Wenn die Erinnerung erscheint, einfach die gewünschte Fertigkeit auswählen.
Nur eine Suchfertigkeit kann gleichzeitig aktiv sein.

Nicht benötigte Felder können leer bleiben.

HINWEIS

Die LOTRO-Lua-API bietet keine zuverlässige Möglichkeit, direkt zu prüfen,
ob eine Suchfertigkeit tatsächlich aktiv ist. GatherReminder verwendet
deshalb den Klick im Erinnerungsfenster als Bestätigung der Auswahl.
